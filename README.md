# Shedule BOT

Telegram-бот для централизованной загрузки и удобного просмотра расписания учебных групп.

## Возможности

- выбор: факультет → направление (где оно есть) → курс → группа;\n- запоминание выбранной группы;
- расписание на сегодня, завтра, ближайшие 3 и 7 дней;
- загрузка расписания администратором из XLSX или CSV;
- русские и английские заголовки таблиц;
- повторный импорт обновляет занятие в том же временном слоте;
- автоматическое создание групп;
- безопасное экранирование текста и разбиение длинных сообщений;
- SQLite из коробки, асинхронная архитектура и готовый Docker-запуск.

## Быстрый запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID, например через [@userinfobot](https://t.me/userinfobot).
3. Скопируйте настройки:

```bash
cp .env.example .env
```

4. Заполните в `.env` значения `BOT_TOKEN` и `ADMIN_IDS`.
5. Запустите:

```bash
docker compose up -d --build
```

Без Docker нужен Python 3.11+:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m schedule_bot
```

## Формат расписания

Администратор отправляет боту файл `.xlsx` или `.csv` как документ. Пример находится в
[`examples/schedule.csv`](examples/schedule.csv).

| Колонка | Русский вариант | Обязательна | Пример |
|---|---|---:|---|
| `faculty` | `факультет` | да | 3 |\n| `specialty` | `направление` | для 2, 3, 4, 7 | Лечебное дело |\n| `course` | `курс` | да | 2 |\n| `group` | `группа` | да | ИС-21 |
| `date` | `дата` | да | 10.10.2026 |
| `start_time` | `начало` | да | 09:00 |
| `end_time` | `конец` | нет | 10:30 |
| `subject` | `предмет` | да | Математика |
| `teacher` | `преподаватель` | нет | Иванов И.И. |
| `room` | `аудитория` | нет | 203 |
| `type` | `тип` | нет | лекция |

Факультеты: 2, 3, 4, 5, 7, 8. Направления: 2 — Лечебное дело; 3 — МПД и Лечебное дело; 4 — Лечебное дело и Стоматология; 7 — Лечебное дело, Стоматология и МПД. Для 5 и 8 колонка направления остается пустой.\n\nПоддерживаемые форматы даты: `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, `ДД/ММ/ГГГГ`.
Размер одного файла ограничен 5 МБ и 20 000 строками. Несколько ID администраторов
указываются через запятую.

## Команды

- `/start` — запуск и выбор группы;
- `/group` — смена группы;
- `/help` — помощь пользователю;
- `/admin` — инструкция по импорту (только для администраторов);\n- `/setgroup Группа | Факультет | Направление | Курс` — распределить ранее загруженную группу.

## Структура

```text
src/schedule_bot/
├── handlers/       # Telegram-команды, кнопки и загрузка файлов
├── services/       # импорт, валидация и форматирование
├── models.py       # модели базы данных
├── repositories.py # запросы к хранилищу
├── keyboards.py    # клавиатуры
├── config.py       # переменные окружения
└── bot.py          # сборка и запуск приложения
```

## Разработка

```bash
pip install -e ".[dev]"
ruff check .
pytest
```

База создаётся при первом старте в `data/schedule.db`. Для production с несколькими
экземплярами бота можно заменить `DATABASE_URL` на PostgreSQL (добавив asyncpg) без изменения
бизнес-логики.
